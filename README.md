# DevOps CI/CD Performance & Delivery Intelligence Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyze DevOps CI/CD pipeline performance, monitor software delivery activities, track deployment outcomes, and provide insights into development and delivery efficiency.

## Project Objectives
- Monitor CI/CD pipeline execution and performance.
- Analyze build and deployment activities.
- Track pipeline success and failure patterns.
- Monitor incidents and infrastructure usage.
- Analyze software testing results.
- Support data-driven DevOps performance improvement.

## Tools & Technologies
- **Microsoft Power BI** – Dashboard development and visualization
- **Power Query** – Data transformation and preparation
- **DAX** – KPI calculations and analytical measures
- **CSV** – Dataset storage and input

## Project Workflow
1. Prepared multiple datasets related to DevOps activities.
2. Loaded datasets into Power BI.
3. Performed data preparation and transformation using Power Query.
4. Created data models and analytical measures using DAX.
5. Developed interactive dashboards to analyze CI/CD performance and delivery intelligence.

## Dataset Description

| Dataset | Description |
|---|---|
| Application_Details | Application information |
| Build_Details | Build execution details |
| Deployment_Details | Deployment information |
| Developer_Details | Developer information |
| Incident_Details | Incident tracking |
| Infrastructure_Usage | Infrastructure utilization |
| Pipeline_Runs | CI/CD pipeline execution |
| Test_Results | Software testing results |
